# FlowPocket (兜兜)

**Your pocket for flowing data. / 流动数据的口袋。 / Votre poche pour les données fluides.**

Designed exclusively for **iPadOS 26**. / 专为 **iPadOS 26** 设计。 / Conçu exclusivement pour **iPadOS 26**.

---

## English

**FlowPocket** is the ultimate temporary transit station for your creative workflow. It acts as a "pocket" where you can temporarily hold data while moving it between apps.

### Why FlowPocket?
- **Built for iPadOS 26**: Optimized for the latest Stage Manager experience.
- **Data Transit Station**: The perfect middleman for extensive copy-pasting.
- **Universal Drop**: Drag text, images, and files in; drag them out when you're ready.
- **Privacy First**: All data is stored locally.
